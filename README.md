# Personalized Job Application Email Automation

## Overview

This project demonstrates how Power Automate can automate personalized job application emails using HR contact details maintained in an Excel spreadsheet.

The workflow dynamically populates email templates with recipient names, company names, and job roles, attaches a resume, and updates the application status.

## Business Problem

Sending personalized job application emails manually is repetitive and time-consuming, especially when applying to multiple companies.

## Solution

A Power Automate cloud flow was designed to:

- Read HR contact details from an Excel table.
- Validate recipient information.
- Generate personalized email content.
- Attach a resume to the email.
- Update the contact's application status.
- Handle skipped or failed records.

## Tools Used

- Microsoft Power Automate
- Microsoft Excel
- Microsoft Outlook

## Workflow

Excel Contact Tracker → Power Automate → Personalized Email → Status Update

## Key Features

- Dynamic email personalization
- Excel-based contact management
- Resume attachment
- Duplicate prevention
- Application status tracking
- Error handling
